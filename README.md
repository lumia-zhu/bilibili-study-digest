# BiliMemo

<img src="icons/icon128.png" alt="BiliMemo" width="80" height="80">

**简体中文** · [English](README.en.md)

在 B 站视频旁阅读字幕、定位片段和整理重点的浏览器扩展。适合看课程、访谈和其他长视频时，一边看，一边查阅原文。

**默认用「跟读」阅读原始字幕，也可切换「段落」集中浏览。** 两种排版、搜索和播放高亮无需 AI 密钥；需要时再翻译或生成概览。

[下载安装包](https://github.com/lumia-zhu/bilibili-study-digest/releases) · [安装步骤](#安装与开始使用) · [常见问题](#常见问题) · [版本记录](CHANGELOG.md)

当前版本为 **[v0.1.16 开发预览](https://github.com/lumia-zhu/bilibili-study-digest/releases/tag/v0.1.16)**，支持 Edge / Chrome，尚未上架扩展商店。采用 MIT 协议，独立维护；[来源与授权说明](#来源与-mit-授权)见文末。

## 能做什么

| 功能 | 使用方式 | 是否调用 AI |
|---|---|---|
| 字幕阅读 | 提供「跟读」「段落」两种排版；支持切换平台提供的字幕轨 | 否 |
| 播放同步 | 播到哪里，对应字幕就高亮；点击字幕或时间戳跳转 | 否 |
| 搜索与回看 | 搜索字幕关键词，定位相关片段；手动滚动后可回到播放位置 | 否 |
| 摘录与导出 | 保存带时间戳的原文摘录，复制或导出 TXT 字幕、Markdown 摘录 | 否 |
| 翻译与解释 | 将英文字幕切换为中文或双语，也可解释选中文字 | 是，按需 |
| 章节概览 | 主动生成章节、要点和原文金句；长视频分批处理 | 是，按需 |

「跟读」保留平台原始字幕片段，使用 16 px 字号、紧凑行距和浅蓝播放高亮，大约每 15 秒显示一个时间入口；每条字幕仍可点击跳转。新视频默认用跟读，已有视频恢复上次保存的排版和阅读位置。

「段落」排版在本地完成，通常每段约 60～90 个汉字；较长停顿会提前换段，单条超长字幕保持完整。段内使用约 3 px 的细间距分隔部分中文片段，短碎片先连读，尽量避开拆开的数字与连接词。文字随侧栏宽度自然折行，不强制短行、不自动补标点。间距仅用于显示，不写入空格；选中文字、搜索、摘录、复制和导出仍使用原文。两种排版都保留片段时间与播放高亮，不调用 AI。「AI 整理断句」继续隐藏。

## 安装与开始使用

### 1. 下载并加载扩展

1. 打开[版本发布页](https://github.com/lumia-zhu/bilibili-study-digest/releases)，下载附件 **`bilimemo-v<version>.zip`**。
2. 解压到一个长期保留的文件夹，确认里面有 `manifest.json`。不要直接选择 ZIP 文件。
3. 在地址栏打开 Edge 的 `edge://extensions`，或 Chrome 的 `chrome://extensions`。
4. 开启「开发者模式」，点击「加载已解压的扩展程序」，选择刚才的文件夹。

### 2. 打开 B 站视频

刷新已经打开的视频页，点击「点赞、投币、收藏、转发」旁的天蓝色「字幕」按钮，或浏览器工具栏里的扩展图标，即可打开侧栏。「字幕」旁的小书签按钮可保存当前片段到摘录。

先试试原始字幕、关键词搜索、点击跳转和保存摘录。这些功能不需要模型 API 密钥；部分平台字幕需要先登录 B 站。如果提示「允许 B 站字幕服务」，按提示授权。

字幕需要更新时，点击条数旁的「刷新字幕」：重新获取当前字幕轨，不使用本地或浏览器 HTTP 缓存。等待期间仍可阅读，失败或超过 30 秒会保留旧内容。刷新后回到原文；内容未变时保留概览，文字或时间变化时清除旧概览，供你按需重新生成。摘录不受影响，刷新不会调用模型；YouTube 刷新会使用已配置的 Supadata 服务及其额度。

### 3. 按需配置 AI

需要翻译或生成概览时，在「设置」中填写自己的 API 密钥、服务地址和模型。默认提供 DeepSeek 配置，也支持兼容 Chat Completions 的服务。模型是否可用取决于服务方和你的账号。

原文阅读不需要完成这一步。填写密钥后，先点「保存设置」，再点「测试连接」。有未保存修改时，测试按钮会提示「需先保存」并禁用；测试会使用已保存的配置，向所选服务发送一次短请求。模型与服务地址可展开修改。

更新时请重新加载扩展，再刷新视频页。保留安装文件夹；移动或删除后可能需要重新加载。Edge 的解压安装可能使用独立副本，请确认更新的是实际加载的目录。

## AI 使用与费用

- 打开视频、阅读原文、切换跟读/段落排版或进入概览页，都不会自动调用 AI。概览需要点击生成。
- 中文/双语翻译、全文翻译、解释、生成概览和测试连接，会在你的操作下调用已配置的服务，可能产生费用。
- 命中本地缓存时不再调用模型；处理失败后可复用成功批次继续。重新生成可能再次计费。
- 「停止后续处理」只停止尚未发出的批次。已经发出的请求以及失败请求仍可能被服务方计费。
- 重新打开视频从原文模式开始。密钥由你在设置中填写，项目不附带密钥。数据流向见[隐私说明](PRIVACY.md)。

## 常见问题

### 能看到字幕，却没有播放高亮或「字幕」按钮？

字幕读取与视频页面连接是两条独立的路径，能加载字幕不代表同步已连接。

如果 Edge 提示 `PAGE_ACCESS_BLOCKED / Blocked`，保持 B 站视频页打开，点击地址栏右侧的扩展拼图图标，检查顶部 **「允许在 bilibili.com 使用扩展」** 开关。允许后刷新视频页，再点击侧栏里的「重新连接播放」。这个站点开关与扩展详情页的访问权限不同。

如果仍然失败，可查看侧栏「同步诊断」里的版本和错误码。其他浏览器策略也可能造成拦截，不能只凭错误码确定原因。「字幕」入口随视频操作栏显示；全屏播放或操作栏未加载时，可使用浏览器工具栏的扩展图标打开侧栏。

### 为什么有些视频没有字幕？

本项目读取 B 站实际提供、当前会话可访问的字幕。有些视频需要登录，有些本来就没有可用字幕。当前版本不提供自动语音转写，也不会绕过内容访问限制。

### 概览会不会只总结视频开头？

长字幕分批处理，并检查各批次是否连续覆盖原始字幕。失败批次会显示对应范围，可重试。覆盖检查不等于事实核验，AI 摘要仍需对照原文确认。

### 可以用在 YouTube 上吗？

当前优先支持 B 站，设置页暂时完全隐藏 YouTube / Supadata 配置。相关代码与已有密钥仍保留，便于以后恢复；保存 AI 设置不会清除已有 Supadata 密钥。YouTube 真实链路尚未完成验收。

## 当前范围

- 支持 B 站普通 BV / AV 视频页和分 P；直播、番剧不在当前范围内。
- 原文、译文和不同字幕轨分开处理；不完整翻译的导出会明确提示，避免被当作完整结果。
- 原文摘录可以保存和导出，暂不提供个人理解笔记编辑器。
- 本地规则只提供阅读间距，不保证按语义准确分组，也不会改写字幕。播放器备用时钟读取只有秒级精度。
- 这是开发预览，尚未完成全部真实视频、登录配置、真实模型和商店安装验收。[验证记录](VALIDATION.md)列出了已测范围与限制。

## 开发与验证

需要 Node.js 22 或更新版本。核心运行与 Node 测试无需安装第三方依赖。

```sh
npm test
npm run check
npm run package
```

可选浏览器测试：

```sh
npm install
npx playwright install chromium
npm run test:browser
npm run test:options
npm run test:extension
```

可通过 `BROWSER_EXECUTABLE` 指定测试浏览器。浏览器测试创建独立临时上下文，使用模拟字幕和模型响应，不读取个人浏览器配置或密钥。发布包按文件白名单生成，不包含测试数据或本地设置。

更多内容见[开发与验收流程](DEVELOPMENT.md)、[验证记录](VALIDATION.md)和[版本记录](CHANGELOG.md)。
