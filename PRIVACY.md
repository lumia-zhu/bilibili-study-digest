# Privacy and data flow

This local extension has no developer server, analytics or telemetry. Settings, API keys, captions, generated results and excerpts are stored in the current browser profile using chrome.storage.local. Keys are not encrypted by this extension and are not synced through an extension account. Use the Settings page to clear caches, delete excerpts or reset all extension data.

Bilibili metadata and captions are fetched in the extension background, bound to the selected video and part. Requests are limited to the Bilibili API and five specified Bilibili caption hosts. API requests use credentials: include, allowing the browser to attach its normal Bilibili session where browser policy permits; caption CDN requests use credentials: omit. The extension has no cookies permission, never reads or copies cookie values, and never includes them in AI prompts. Dynamic script injection is not needed to read Bilibili captions; playback controls still use content scripts. No login bypass, automatic audio download or ASR fallback is implemented. YouTube caption retrieval sends the video URL and the user's Supadata key to Supadata.

Explicit AI actions send the relevant caption text, selected text and video context to the configured AI provider with the user's API key. The default endpoint is DeepSeek; users can configure another compatible provider. Custom provider access is requested for its domain when settings are saved. Connection testing sends a short test message, not video content. Provider logging, retention and billing policies apply. This fork has no access to the user's provider account.

Caption cleanup and overview generation are never automatic on page load. Chinese/bilingual mode translates visible source segments after the user selects it. A full-translation action processes all segments. Stop prevents further batches; requests already sent cannot reliably be recalled. Generated chunk caches expire after 30 days and are bounded by count and approximate size. Browser storage quotas may still be reached; persistence failure is reported.

Export and clipboard actions place content in a user-selected download or the system clipboard. Clearing extension storage does not remove exported files. Uninstalling removes the extension's browser storage.
