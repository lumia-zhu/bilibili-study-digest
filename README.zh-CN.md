# B 站学习 Digest

基于 [Zara Zhang / youtube-digest](https://github.com/zarazhangrui/youtube-digest) 的独立实验版本。优先完善 B 站学习体验，保留 YouTube 兼容入口。当前版本 0.1.5，尚未上架扩展商店，也不是 Zara 的官方版本。

[下载 v0.1.5 开发预览](https://github.com/lumia-zhu/bilibili-study-digest/releases/tag/v0.1.5) · [版本记录](CHANGELOG.md) · [MIT 许可证](LICENSE) · [完整来源说明](NOTICE.md)

## 本版行为

- 默认显示原始字幕，不调用模型。浮动按钮、扩展图标均可打开侧栏。
- 原始字幕默认按段落阅读，可切换「段落／逐句」。本地根据停顿、已有标点和长度排版，不修改原文；每段一个时间入口，段内按原字幕片段高亮和跳转。切换尽量保持阅读位置，当前视频的排版与位置一起保存。
- 搜索字幕、时间戳跳转、播放位置高亮与滚动跟随、字幕轨选择。手动滚动后仍更新高亮，点击「回到播放位置」恢复跟随；这些操作不调用 AI。
- 点击「AI 整理断句」才处理：只调标点和分段，保留原文开关；拒绝遗漏、重排或文字数字被改写的批次。
- 英文字幕支持中文、双语与全文翻译。切换中文/双语会按需调用模型；重新打开视频仍从原文开始。
- 概览需要点击生成。长字幕分批生成章节、要点、原文金句；校验每批字幕连续覆盖，不静默截断。只保证覆盖范围，摘要准确性仍需核对。
- 失败显示时间范围；再次点击复用成功缓存。停止按钮阻止后续批次，已发送请求可能继续完成并计费。
- 时间戳摘录、原文金句收藏、选中文字解释。保存摘录不调用 AI；暂不提供个人理解编辑器。
- 复制 / TXT 字幕导出，时间戳可选。未完成翻译须确认导出部分结果并明确标注。摘录支持 Markdown 导出。
- 本地缓存，设置页可清缓存、删除摘录或重置数据；兼容 Chat Completions 的 AI 服务可自填地址和模型。

## 本地安装

1. 将源码或发布 ZIP 解压到长期保留的目录，确认目录内有 `manifest.json`。
2. 打开 Edge 的 `edge://extensions` 或 Chrome 的 `chrome://extensions`，开启开发者模式，选择「加载已解压的扩展程序」，选择上述目录。ZIP 需要先解压。
3. 刷新已经打开的 B 站视频页。点击右下「Digest · 字幕」，或工具栏扩展图标。
4. 先检查原始字幕、搜索、跳转和摘录；这些 B 站功能无需模型 API 密钥。
5. 需要 AI 时，在设置中填写自己的密钥、服务地址、模型并保存。默认沿用上游 DeepSeek 配置；模型可用性取决于账号和服务方。测试连接会发送一次短请求。

请保留安装目录；移动目录后需重新加载。更新代码后在扩展管理页点击刷新，再刷新视频页。

0.1.2 改为在扩展后台通过 B 站接口读取视频信息与字幕，加入 WBI 签名及备用字幕接口，移除了读取字幕时的动态页面脚本注入依赖。更新后先重新加载扩展，再刷新已打开的视频页。如果提示「允许 B 站字幕服务」，点击按钮授权 B 站 API 与字幕 CDN。Edge 解压安装可能使用独立副本，修改开发目录不会自动更新那个副本。浮动按钮、播放跳转仍使用页面内容脚本。

0.1.3 修复播放时间读取不到却被当成 0 秒的问题，增加主播放器优先选择、播放器显示时钟备用读取和同步状态提示。暂停、向前/向后拖动进度均会更新对应字幕高亮；字幕间隙不保留过时高亮。备用时钟只能提供秒级位置，精度低于原生播放器时间。

0.1.4 起将播放进度改为侧栏直接读取页面接收器，失败时再尝试后台恢复；只跟随侧栏所属窗口的当前视频。连接失败时显示具体错误码，可点击「重新连接播放」恢复 B 站页面访问权限与接收器。「同步诊断」包含版本、视频标识和错误详情，不含密钥。侧栏顶部显示当前版本号。字幕服务权限与视频页面访问权限不同，能读到字幕不代表播放连接已建立。

**Edge 提示 `PAGE_ACCESS_BLOCKED / Blocked` 且没有浮动按钮：**保持 B 站视频页打开，点击地址栏右侧的扩展拼图图标，检查顶部「允许在 bilibili.com 使用扩展」站点开关，允许后刷新视频页。它与扩展详情页的权限开关相互独立；仅有扩展自身的站点权限不足以覆盖站点级禁用。其他浏览器策略也可能造成拦截，错误码本身不能唯一确定原因。

## 范围与限制

0.1.5 的段落是阅读排版，不是语义摘要：优先在明显停顿或完整标点处分段，限制约 30 秒或 150 个汉字等量长度；单条超长源字幕保留完整。没有标点的原文不会自动添加标点。AI 整理仍需主动点击，已有 AI 整理结果保留它自己的段落范围。复制与导出继续使用原来的内容和时间粒度。

- B 站只读取平台实际提供且当前会话可访问的字幕，部分字幕需要先登录 B 站。没有字幕时显示原因，不做隐藏音频下载或自动转写。
- 本期支持 `www.bilibili.com/video/BV...` 普通视频和分 P。直播、番剧、付费字幕绕过不在范围内。
- 字幕源用 BVID / CID / 分 P 校验。不同字幕轨与内容使用不同翻译、整理缓存。
- YouTube 保留上游 Supadata 字幕流程，需要单独的 Supadata key；本次以 B 站为测试重点。
- AI 整理、翻译、概览、解释均可能计费。价格由所选服务决定，缓存命中不发模型请求。重新生成会再次调用。
- 自定义服务需支持 `/chat/completions`、JSON 输出和常见消息格式。只允许 HTTPS 或本机 HTTP；保存新域名时浏览器请求对应站点权限。
- 这不是已验证的商店发布版。自动化与真实网站验证范围见 [VALIDATION.md](VALIDATION.md)。

## 开发与验证

Node.js 22+，核心运行与单元测试无需第三方依赖。

```sh
npm test
npm run check
npm run package
```

可选浏览器验证：`npm install` 后执行 `npx playwright install chromium`，再 `npm run test:browser` 和 `npm run test:extension`。支持用 `BROWSER_EXECUTABLE` 指定测试浏览器路径；测试创建独立临时上下文，使用模拟字幕和模型响应，不读取个人浏览器配置或密钥。

开发步骤及真实视频验收表见 [DEVELOPMENT.md](DEVELOPMENT.md)。
