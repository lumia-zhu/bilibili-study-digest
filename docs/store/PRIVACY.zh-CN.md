# BiliMemo 隐私说明

适用于 Microsoft Edge 的 B 站商店版 v0.1.20。Chrome 商店版使用相同安装包和数据处理方式。更新于 2026 年 11 月 22 日。

BiliMemo 帮你在观看哔哩哔哩视频时阅读字幕、定位原句和保存摘录。原文阅读、播放高亮、搜索和摘录都在你的浏览器中完成。读取字幕需要连接哔哩哔哩；使用可选的 AI 功能还会连接你在设置中选定的服务。开发者没有接收这些内容的服务器，扩展不含广告、使用统计或遥测。

## 阅读字幕和跟随播放

扩展根据 B 站页面地址识别当前视频和分 P，向哔哩哔哩请求视频信息、字幕轨和字幕正文，并读取播放器进度来高亮当前原句。需要登录才能查看的字幕，由浏览器按自身规则向 B 站 API 附带现有登录状态。扩展不读取或复制 Cookie。向字幕文件域名请求正文时不附带登录凭据。

这些请求使用 `www.bilibili.com`、`api.bilibili.com`、`subtitle.bilibili.com`、`aisubtitle.hdslb.com`，以及 `i0.hdslb.com`、`i1.hdslb.com`、`i2.hdslb.com`。播放同步只读取视频进度；扩展不录制或上传音视频。

## 哪些操作会把内容发给 AI 服务

默认服务是 DeepSeek。你也可以指定兼容接口，保存自定义服务设置时，扩展会向浏览器申请访问该服务域名的权限。浏览器直接向所选服务发送请求，用你填写的密钥验证身份。远程接口使用 HTTPS，本机服务也支持回环地址上的 HTTP。

| 你使用的功能 | 所选服务会收到什么 |
|---|---|
| 生成或重新生成概览 | 视频标题和分批处理的字幕原文，含时间和段落标识 |
| 切换到中文或双语翻译 | 视频标题及需翻译的字幕、概览或摘录。在字幕视图中，滚动阅读会继续翻译附近的片段；选择翻译全文会处理整份字幕 |
| 解释选中的文字 | 所选文字、相关字幕上下文和视频标题 |
| 测试已保存的连接 | 一条简短测试消息和请求使用的模型名称，不含视频内容 |

浏览器会记住各视频的翻译模式，再次打开同一视频时可能继续请求缺少的译文。切回「原文」可结束该翻译模式。对于提供「停止后续处理」的分批任务，停止会阻止后续批次，已发送的请求可能仍会完成。服务商依其政策处理收到的数据，并可能按用量计费。

## 浏览器保存什么，如何删除

当前浏览器配置会保存设置和阅读偏好、你输入的 API 密钥、已读取视频的字幕与学习进度、翻译和概览缓存，以及你主动保存的摘录。摘录包含原文、视频标题、作者、时间和回跳链接。扩展使用本地存储，不通过 BiliMemo 账号同步。扩展本身不单独加密保存在浏览器中的密钥。

- **清除缓存**会清除本地字幕、概览和翻译等视频缓存。AI 分批结果最多复用 30 天，并在后续写入时按时间、数量及大小清理。
- **删除摘录**可以在「摘录」中逐条操作，也可以在设置中点击「删除全部摘录」。摘录保留到你删除或重置为止。
- **移除密钥**可以在设置中清空密钥后保存。「重置扩展数据」可清除学习数据和密钥，并保留界面语言。卸载扩展会移除其浏览器本地存储。
- **复制与导出**会将你选择的内容写入系统剪贴板或保存为本地文件。已导出的文件由你管理。清除浏览器内的数据不会删除服务商已经收到的数据。
